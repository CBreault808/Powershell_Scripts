# Powershell Scripts 

## Overview 
This repository is built to store common Powershell scripts and tools used for troubleshooting and testing. 

1. `ping_check.ps1` - Basic script tool used to check if IP addresses are active. Script comes with a modifiable text file that can be loaded with any amount of IP addresses to check. The script will then parse through the text file and ping each address with one packet, displaying in green if the address is online or red if the address is offline.
